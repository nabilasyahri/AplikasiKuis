## 📋 Informasi Aplikasi
* **Nama Aplikasi**: Multiple Choice Quiz
* **Deskripsi Singkat**: Aplikasi kuis interaktif yang dirancang untuk menguji pengetahuan umum melalui soal pilihan ganda. Dilengkapi dengan fitur manajemen profil, tema ganda (Dark/Light Mode), serta tampilan UI dengan style *Soft Dashboard* yang responsif untuk berbagai ukuran layar.
* **Fitur-Fitur Utama**:
  1. **Dynamic Welcome & Profile**: Input nama pengguna yang terintegrasi secara global ke seluruh halaman.
  2. **Interactive Quiz Workflow**: Navigasi soal (Sebelumnya / Selanjutnya), pemilihan opsi jawaban berbasis *badge* abjad (A, B, C, D), serta kalkulasi skor akhir otomatis.
  3. **Dual Theme (Dark & Light Mode)**: Dukungan mode terang dan gelap yang dapat diubah secara instan melalui ikon switch.
  4. **Adaptive & Responsive Layout**: Kompatibel dengan perangkat mobile, tablet, maupun browser web dengan pembatasan lebar optimal agar tata letak tetap rapi.
